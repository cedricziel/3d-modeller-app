# CAD 05: Naming geometry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Faces and edges get stable names from the feature that created them, features refer to geometry by name or by filter, and fillet, chamfer and shell work on those references, with a `find_geometry` tool and bench tasks that exercise them.

**Architecture:** `CADKernel` names every face when it creates or changes a solid (primitive roles in the local frame, OCCT generated/modified/deleted history for booleans, fillets, chamfers and shells, index order for rigid transforms) and reports per-face and per-edge descriptors. `CADModel` mirrors the descriptors as pure data (`BodyTopology`), gives each face and edge a unique display name, stores references as `GeometryReference.name`/`.filter` and resolves them on every rebuild against the target body; ambiguity and no-match fail the feature with a candidate list. `CADAssistantTools` adds the new feature kinds to `add_feature`/`edit_feature`, rewrites references on rename, lists references readably and adds `find_geometry`.

**Tech Stack:** Swift 6 (tools 6.1), Swift Testing, OCCTSwift 3.0.0 (`*WithFullHistory`, `ShapeHistoryRef`, `Face`, `Edge`, `Surface.*Properties`, `Curve3D.circleProperties`), `CADModel`, `CADAssistantTools`, `CADBench`.

**Spec:** `docs/superpowers/specs/2026-09-26-cad-roadmap-design.md` (sections "Naming geometry", "Agent tools", PR-stack row 5). Previous layer: `docs/superpowers/plans/2026-09-26-cad-04-bench.md`.

## Spike findings (OCCTSwift 3.0.0, measured before writing this plan)

- `Shape.box` faces in `subShapes(ofType: .face)` order: −X, +X, −Y, +Y, −Z, +Z. `Face.normal` of a planar face points out of the solid.
- `Kernel.placed` (`BRepBuilderAPI_Transform`, copy) keeps face and edge enumeration order, so names transfer by index.
- Boolean history: unchanged faces are the same TShape in the result (`isSame`), changed faces appear in `record(of:).modified` (tool faces too), faces fully removed are `isDeleted`.
- `filletedWithFullHistory` / `chamferedWithFullHistory` take indices into `edges()`, which match `subShapes(ofType: .edge)`. The filleted edge is deleted and `generated` holds the new face. Untouched faces stay `isSame`; trimmed ones are `modified`.
- `shelledWithFullHistory(facesToRemove:thickness:)` offsets **outward** for a positive thickness. Original faces stay `isSame`; each generates its offset face; the removed face is `modified` into the rim.
- `Shape.adjacentFaces(forEdge:)` returns indices into the face enumeration.
- Surface parameters: `faceSurfaceGeom()?.cylinderProperties` (radius, axis), `.coneProperties.axis`, `.sphereProperties` (centre, radius); edge circles via `Edge.curve3D?.circleProperties` (centre, radius, x/y axes). Down-casts return 0 on a type mismatch.

## Rulings

- **Ruling: each face carries a list of names, primary first.** A face merged from several inputs (a union of flush boxes) keeps every input name; the target's names come first. Cost if wrong: a merged face answers to more than one name, which an agent might not expect.
- **Ruling: names use feature names, not ids; `rename_feature` rewrites references.** Names like `Box1.top` are what agents read. Renaming rewrites `Old.` prefixes in every name and filter reference of the part. Deleting a feature does not refuse; references to its faces fail at rebuild with the candidate list. Cost if wrong: a reference written by hand with a different spelling survives a rename unchanged.
- **Ruling: a name reference must match exactly one face or edge; a filter may match any positive number.** A face split into pieces gets display names `Box1.top[0]`, `Box1.top[1]` (pieces ordered by centroid x, then y, then z); `Box1.top` then fails as ambiguous, listing the pieces. Edges are named `edge(A, B)` from their adjacent faces' primary names (sorted), with `[i]` when several edges share the pair (ordered by midpoint). `edge(B, A)` also resolves. Cost if wrong: an agent that meant "all pieces" must name each.
- **Ruling: new faces are named after the feature.** Faces a fillet or chamfer generates from an edge: `Fillet1.face[i]` in edge order; faces a shell generates from a face `X`: `Shell1.inner[X]`; every other unnamed face: `<Feature>.face[k]`, with `k` the next free index. Cost if wrong: indices shift when the selected edges change.
- **Ruling: filter grammar.** `[edges|faces] clause (and clause)*` with clauses `parallel X|Y|Z`, `perpendicular X|Y|Z`, `normal [+|-]X|Y|Z` (faces), `type <surface or curve type>`, `circular [r=<expr>]`, `farthest [+|-]X|Y|Z`, `on <face name>` (edges). Clauses apply left to right; `farthest` keeps the entities whose centre is furthest along the direction among those matched so far (0.001 mm tolerance). `r=` accepts parameter expressions. Cost if wrong: grammar extensions later are additive.
- **Ruling: references are stored as `{"name": …}` or `{"filter": …}`; tools accept strings.** A tool string whose first word is a filter keyword (`edges`, `faces`, `parallel`, `perpendicular`, `normal`, `type`, `circular`, `farthest`, `on`) is a filter; anything else is a name. Cost if wrong: a feature named after a keyword cannot be referenced by a bare name starting with that word (names always contain a `.` or start with `edge(`, so this cannot happen).
- **Ruling: shell thickness is positive inward.** The wall stays inside the original outline; the kernel passes `-thickness` to OCCT. Cost if wrong: none; negative values are rejected.
- **Ruling: `BodyResult.topology` is computed for every body on every rebuild.** Tools and later UI selection read it without another replay. Cost if wrong: extra milliseconds per body on large models.
- **Ruling: `EdgeQuery` and `Kernel.fillet(_:edges: EdgeQuery…)` are removed.** Selection moved to `CADModel`; the kernel takes indices. Cost if wrong: none; nothing outside kernel tests used them.
- **Ruling: the outline Delete goes through the session.** `CADSession.deleteFeature(id:)` runs the same write pipeline as `delete_feature` (body-reference repair, refusal); the app shows a refusal in an alert. Cost if wrong: the delete now waits for a rebuild before the undo step lands (sub-second).

- **Ruling (execution): a shell that OCCT answers with a valid-looking wrong solid fails.** With walls that would meet, `shelledWithFullHistory` returns a valid solid that is not a shell. The kernel requires a smaller, positive volume and more faces than the input. Cost if wrong: a legitimate shell with fewer faces than its input would be refused; none is known.
- **Ruling (execution): face area and centroid come from `Shape.surfaceInertia` (`BRepGProp::SurfaceProperties`).** `Face.surfaceInertia` integrates the untrimmed surface and ignores holes. Cost if wrong: none.
- **Ruling (execution): a fillet or chamfer fails when OCCT skips a selected edge.** OCCT silently leaves a seam sharp; an edge that generated no face fails the feature and names its index. Filters never pick seam edges, so `parallel Z` on a drilled plate works; a name can still pick a seam and then fails. Cost if wrong: the error names a kernel edge index, not the edge's name.
- **Ruling (execution): a name that several faces carry is ambiguous even when it is one face's display name.** After a union, the overlap face carries both boxes' top names; `Box2.top` then matches two faces and fails with both listed. Cost if wrong: an agent must use a piece name (`Box1.top[1]`) more often.
- **Ruling (execution): filter `r=` expressions are audited like numeric fields.** Cost if wrong: none.
- **Ruling (execution): CADKernel tests run with `--scratch-path Packages/CADModel/.build`.** Disk is tight; CI still runs `xcrun swift test` in `Packages/CADKernel`. Cost if wrong: none.

## Review Focus

1. A face split by a later boolean. Expected: display names `X[0]`, `X[1]`; a bare `X` fails as ambiguous and lists both. Pinned in Task 5 (`splitFaceAmbiguous`) and Task 6 (`namesSurviveBooleanSplit`).
2. A reference to a feature that was deleted or renamed. Expected: rename rewrites; delete leaves a failing feature whose error lists the body's faces or edges. Pinned in Task 8 (`renameRewritesReferences`, `deleteLeavesFailingReference`).
3. A fillet radius too large or a shell that OCCT refuses. Expected: `failed: …` status, later independent features still build, no crash. Pinned in Task 3 (`filletTooLarge`, `shellTooThick`).
4. A filter with a typo or wrong kind (`normal +Z` on edges, `farthest +Q`). Expected: the feature fails, or `find_geometry` refuses, naming the bad clause and the accepted forms. Pinned in Task 5 (`filterErrors`) and Task 9 (`findGeometryRefusals`).
5. A fillet on a body that a transform moved. Expected: names follow the body; references still resolve. Pinned in Task 2 (`transformKeepsNames`) and Task 6 (`filletAfterTransform`).

```swift
static func roleNames(_ shape: Shape, feature: String, roles: (FaceInfoRaw) -> String) -> [[String]] {
    shape.subShapes(ofType: .face).map { face in
        guard let f = Face(face) else { return ["\(feature).face"] }
        return ["\(feature).\(roles(FaceInfoRaw(type: f.surfaceType, normal: f.normal ?? .zero)))"]
    }
}
// box: dominant normal axis/sign → left/right/front/back/bottom/top
// cylinder/cone: .plane → normal.z > 0 ? "top" : "bottom", else "side"; sphere/torus: "surface"
```

### Task 5: Display names, references, filters and resolution

**Files:** Create `TopologyNames.swift`, `GeometryReference.swift`, `GeometryFilter.swift`, `GeometryResolver.swift`; tests `TopologyNamesTests.swift`, `GeometryFilterTests.swift`, `GeometryResolverTests.swift`.

**Interfaces — Produces:**

```swift
public struct TopologyNames: Sendable, Equatable {
    public let faces: [String]; public let edges: [String]
    public init(_ topology: BodyTopology)
}
public enum GeometryReference: Sendable, Hashable, Codable, CustomStringConvertible {
    case name(String), filter(String)
    public init(parsing text: String)          // keyword rule
    public func renamingFeature(_ old: String, to new: String) -> GeometryReference
}
public struct GeometryFilter: Sendable, Equatable {
    public init(parsing text: String, kind: GeometryKind) throws(ReferenceError)
    public func select(_ candidates: [Int], in topology: BodyTopology, names: TopologyNames,
                       evaluate: (String) throws(ReferenceError) -> Double) throws(ReferenceError) -> [Int]
}
public struct ReferenceError: Error, Sendable, Equatable, CustomStringConvertible { public let description: String }
public enum GeometryResolver {
    public static func resolve(_ references: [GeometryReference], kind: GeometryKind, in topology: BodyTopology,

}
```

Edges of this body: …", at most 25 candidates then "… and N more; call find_geometry"). Filters: at least one match. The union of all references, sorted.
